## ✨ Overview

The **Prophet Muhammad ﷺ Tribute Page** is a modern editorial-style website created to present a respectful visual reflection on the life, character, teachings, mission, and enduring legacy of Prophet Muhammad ﷺ.

The design intentionally avoids portraits or human representations of the Prophet ﷺ. Instead, it uses architectural imagery, Islamic-inspired geometric elements, Arabic typography, subtle gold accents, and carefully structured layouts to create a peaceful and timeless experience.

The project was built entirely with **HTML5 and CSS3**, with a strong focus on visual hierarchy, responsive design, typography, spacing, accessibility, and user experience.

---

## 🎯 Project Goals

The main goals of this project were to:

- Create a respectful digital tribute
- Practice professional HTML and CSS development
- Build a strong visual hierarchy
- Develop a cinematic hero section
- Create responsive layouts for different screen sizes
- Implement both dark and light visual themes
- Use Islamic-inspired design elements subtly
- Practice modern frontend design principles
- Create a polished portfolio-quality website
- Demonstrate that a visually rich website can be created without a JavaScript framework

## 🌟 Features

### 🏛️ Cinematic Hero Section

The landing section introduces the tribute with:

- Arabic calligraphy
- Prophet Muhammad ﷺ heading
- Supporting tagline
- Short introduction
- Architectural background imagery
- Dark gradient overlay
- Islamic-inspired decorative elements
- Scroll indicator
- Call-to-action button

The hero section was designed to create a calm, elegant, and respectful first impression.

---

### 📖 His Life

A dedicated biography section presents a concise overview of:

- His early life
- His mission
- His character
- His compassion
- His influence

The section uses a structured editorial layout to maintain readability while keeping the visual design clean and minimal.

---

### 🕰️ Journey of a Messenger

A chronological timeline highlights important moments in the life of Prophet Muhammad ﷺ:

| Year       | Milestone                       |
| ---------- | ------------------------------- |
| **570 CE** | Birth in Makkah                 |
| **610 CE** | First Revelation                |
| **622 CE** | Hijrah to Madinah               |
| **630 CE** | Return to Makkah                |
| **632 CE** | Farewell Pilgrimage and Passing |

The timeline adapts from a horizontal layout on larger screens to a vertical layout on smaller screens.

---

### 🤍 Character & Values

The website highlights important qualities associated with the character and teachings of Prophet Muhammad ﷺ, including:

#### MERCY

> Compassion toward people and creation.

#### JUSTICE

> Fairness, honesty, and responsibility.

#### COMPASSION

> Kindness, patience, and care for others.

The cards use subtle visual details and restrained decoration to maintain the overall peaceful aesthetic.

---

### ✒️ Quote Section

A dedicated quote section presents:

> “Indeed, I was sent to perfect good character.”

A source/reference label is provided beneath the quotation to encourage responsible attribution.

---

### 🌍 An Enduring Legacy

The legacy section focuses on the continuing influence of Prophet Muhammad ﷺ through:

- Character
- Teachings
- Compassion
- Guidance
- Community
- Positive influence across generations

The section uses a centered editorial layout with restrained decorative elements.

---

### 🌓 Dark & Light Modes

The website includes two visual themes:

- **Dark Mode** — near-black, charcoal, off-white, and muted gold
- **Light Mode** — warm off-white, soft beige, charcoal, and muted gold

Both themes maintain the same visual identity while providing different viewing experiences.

## 🎨 Design System

### Color Palette

| Color          | Purpose                 |
| -------------- | ----------------------- |
| **Near Black** | Primary dark background |
| **Charcoal**   | Secondary surfaces      |
| **Off-White**  | Main typography         |
| **Muted Gold** | Accents and highlights  |
| **Warm Beige** | Light-mode background   |
| **Soft Gray**  | Supporting text         |

The palette was intentionally kept restrained to create a sophisticated, peaceful, and timeless visual identity.

---

## 🔤 Typography

The project uses complementary typography styles to establish a clear visual hierarchy.

### Serif Typography

Used for:

- Hero headings
- Section titles
- Quote typography
- Editorial content

### Sans Serif Typography

Used for:

- Navigation
- Body text
- Labels
- Supporting information

### Arabic Typography

Arabic-compatible typography is used for Arabic text and calligraphic elements to maintain readability and visual balance.
