# 🧮 Calcora Scientific

A modern, responsive scientific calculator built with **HTML5, CSS3, and Vanilla JavaScript**.

Calcora Scientific combines a clean premium interface with practical calculator functionality, including basic arithmetic, scientific operations, calculation history, keyboard interaction, and light/dark themes.

---

## ✨ Overview

**Calcora Scientific** is designed as a professional web-based calculator that provides both basic and scientific mathematical operations in a simple and accessible interface.

The project focuses on:

- Clean and modern UI design
- Responsive user experience
- Scientific calculator functionality
- Simple and intuitive interactions
- Accessibility and keyboard support
- Light and dark themes
- Error handling
- Reusable interface components

---

## 🚀 Features

### 🧮 Basic Calculator

- Addition
- Subtraction
- Multiplication
- Division
- Decimal numbers
- Percentage
- Clear / AC
- Backspace
- Operator chaining
- Expression display
- Result display
- Division-by-zero error handling

### 🔬 Scientific Calculator

Calcora Scientific includes commonly used scientific functions:

- `sin`
- `cos`
- `tan`
- `sin⁻¹`
- `cos⁻¹`
- `tan⁻¹`
- `√`
- `x²`
- `xʸ`
- `ln`
- `log`
- `π`
- `e`
- Parentheses
- Percentage
- Factorial
- Positive / negative values

### 🌓 Light & Dark Mode

Switch between light and dark themes to match different environments and user preferences.

### 📜 Calculation History

Previous calculations are displayed in a dedicated history panel.

Users can:

- View previous calculations
- Reuse previous calculations
- Delete individual history items
- Clear calculation history

### 📋 Copy Result

Copy the current calculator result with a single click.

### ⌨️ Keyboard Support

Calcora Scientific supports keyboard interaction for faster calculations.

### ⚠️ Error Handling

The calculator provides clear feedback for invalid operations, including:

- Division by zero
- Invalid expressions
- Invalid scientific operations
- Empty input

### 📱 Responsive Design

The interface is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile devices

The scientific functions are organized to keep the interface usable on smaller screens.

---

## 🎨 Design

Calcora Scientific uses a premium technical visual style.

### Design principles

- Minimal interface
- Strong visual hierarchy
- High contrast
- Subtle borders
- Dark charcoal surfaces
- White and light-gray typography
- Gold accent color
- Clear button hierarchy
- Large touch-friendly controls

The goal was to create something that feels more like a **professional scientific tool** than a basic calculator demo.

## 🛠️ Technologies

This project was built entirely with:

| Technology         | Purpose                                             |
| ------------------ | --------------------------------------------------- |
| HTML5              | Structure and semantic markup                       |
| CSS3               | Styling, responsive layout, themes and interactions |
| Vanilla JavaScript | Calculator logic and user interactions              |

No frameworks or external UI libraries are required.
